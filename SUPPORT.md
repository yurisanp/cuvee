# Suporte

O suporte do Cuvée é feito pelas
[issues do GitHub](https://github.com/yurisanp/cuvee/issues).

1. Rode `cuvee doctor` e siga o que ele indicar. A maioria dos problemas de
   instalação aparece ali, com o comando que resolve.
2. Veja a aba **Comportamento** do app: ela diz o que é normal para cada versão
   do macOS (por exemplo, sem aceleração do 10.13 ao 15).
3. Se não resolver, abra uma issue com o modelo **Problema / Bug** e anexe o
   arquivo do `cuvee report`.

O Cuvée é um projeto pessoal mantido no tempo livre. Não há prazo de resposta.

## O que não é suportado

- Rodar macOS em hardware que não seja da Apple pode violar a licença do macOS.
  Você é responsável por usar o Cuvée dentro dela.
- O Cuvée não distribui o macOS. Ele é baixado direto dos servidores da Apple.
- Problemas do [reims-vgpu](https://github.com/steelbrain/reims-vgpu) em si
  vão para o repositório dele. Se não souber de qual projeto é, abra aqui.
